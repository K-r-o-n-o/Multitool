Start-up crash fix + Hello/anti-kill hardening (v1.4.1)

- Fix start-up crash: a security-module timer (WinGuard) read its state before
  it was initialized; state is now assigned in the GLOBAL STATE block before
  STARTUP, matching the existing SentinelPID pattern.
- Windows Hello gate for opening Windows Settings (close -> verify -> reopen;
  a killer keeps it closed while the prompt is pending).
- Per-target Hello options: Settings, sentinel-off, release/token, quit, and
  Windows Settings -- each independently toggleable.
- Opt-in "Resist being killed": deny-terminate ACL + hidden wscript watchdog;
  watchdog arming deferred 3s so a startup crash can't loop-resurrect.
